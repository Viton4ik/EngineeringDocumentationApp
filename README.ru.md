# GASTRANS Engineering Documentation

[English](README.md) · **Русский**

Веб-каталог инженерной документации, который работает на обычном Windows-ПК. Сотрудники в локальной сети ищут и просматривают любые документы прямо в браузере, ничего не скачивая. Они также могут предлагать новые документы: в каталог те попадают только после одобрения администратора. Администратор работает в защищённой паролем панели со статистикой, диаграммами, сообщениями и блокировкой устройств.

Интерфейс на трёх языках: русский, сербский (латиница), английский.

## Возможности

### Для сотрудников
- **Каталог**: таблица с поиском и сортировкой, дерево папок, фильтры (тип, документация, RFQ, система, UNIT, дата, размер), избранное, экспорт CSV.
- **Открытие в один клик**: двойной щелчок по строке, Enter или кнопка **↗ Открыть** вверху панели предпросмотра.
- **Предпросмотр почти любых файлов**:
  - PDF, изображения (TIFF конвертируется), видео и аудио (AVI/MKV/WMV через ffmpeg);
  - Word / Excel / PowerPoint / Visio / RTF / ODF через LibreOffice;
  - текст, CSV, письма `.eml`, содержимое `.zip`.
- **Без скачивания без согласия**: файл сохраняется на ПК только кнопкой **Скачать…** после подтверждения.
- **В программе**: Word, Excel, AutoCAD и т.д. открывают файл прямо из сетевой папки. Для Office используются ссылки `ms-word:`, для остального есть необязательный помощник, который ставится один раз.
- **Присутствие**: в шапке «Вы подключены: Имя · ИМЯ-ПК». Имя ПК определяется автоматически, учётная запись не нужна.
- **Заявки на документы**: форма с названием, описанием, типом, ревизией, папкой назначения, комментарием и файлами (перетаскиванием, по умолчанию до 500 МБ). Возвращённую заявку можно исправить и отправить снова.
- **Сообщения**: входящие от администратора (важные всплывают окном) и ответы.
- **Автоматические названия**: для файлов без сопоставления Siemens сервер читает первую страницу (PDF, DOCX, PPTX, XLSX, TXT) и показывает название документа.

### Для администратора (`/admin`, учётная запись `admin`)
- **Цветные карточки**:
  - 🟧 новые заявки
  - 🟦 исправленные после доработки
  - 🟪 непрочитанные сообщения
  - 🟥 неудачные входы и попытки заблокированных
  - 🟩 одобрено сегодня
  - онлайн сейчас
- **Диаграммы**: активность по дням, уникальные ПК, действия, тепловая карта по дням недели и часам, активные сотрудники, популярные документы, ОС, браузеры, заявки по статусам. У каждой диаграммы есть табличный вид.
- **Подключения и сотрудники**: имя, имя ПК, IP, ОС (Windows 10 / 11 в Chrome и Edge), браузер, экран, первый и последний вход, число визитов. Предупреждение, если с одного ПК входили под разными именами.
- **Рассмотрение заявок**:
  - просмотр файлов и правка описания;
  - одобрение, возврат на доработку с сообщением, отклонение, удаление.
  - При одобрении файлы проверяются Windows Defender и копируются в каталог.
  - Одобрять можно с любого ПК: файлы копирует сам сервер своей учётной записью Windows, поэтому общая папка для сотрудников остаётся «только чтение». `APPROVE_ONLY_ON_SERVER=1` разрешает одобрение только на ПК сервера.
- **Блокировка** сразу по IP, имени ПК и браузеру (достаточно совпадения любого признака), с причиной и сроком. Сам сервер заблокировать нельзя.
- **Сообщения** любому сотруднику: общие или в ветке заявки.
- **Журнал** с фильтрами по датам, ПК, сотруднику, IP, действию и документу, экспорт CSV.
- **Настройки**: смена пароля admin, состояние системы (LibreOffice, ffmpeg, Defender, сетевая папка, право записи, лимиты загрузки).

Всё хранится в `data/portal.db` (SQLite) и сохраняется после перезапуска: журнал, устройства, блокировки, заявки, сообщения и вход администратора.

## Требования
- Windows 10/11 или Windows Server, **Python 3.10+**.
- Рекомендуется [LibreOffice](https://www.libreoffice.org/) для точного предпросмотра документов Office.
- По желанию: `ffmpeg.exe` в `C:\ffmpeg\bin\` для AVI / MKV / WMV.
- Windows Defender (встроен в Windows) для проверки файлов заявок.

## Установка
1. Скопируйте папку `doc_portal` на серверный ПК.
2. Откройте общий доступ к `C:\Documentation` (**только чтение** для сотрудников) с именем ресурса `Documentation`. При другом имени поменяйте `DOC_SHARE`.
3. Проверьте настройки в `start_windows.bat`.
4. Запустите `start_windows.bat`. При первом запуске он:
   - создаёт виртуальное окружение и устанавливает зависимости;
   - **спрашивает пароль для `admin`** (минимум 6 символов). Пароль хранится только как хеш scrypt.
5. Разрешите входящий TCP 8080 в Windows Firewall для профиля Private/Domain.
6. Сотрудники открывают `http://ИМЯ-СЕРВЕРА:8080`, администратор открывает `http://ИМЯ-СЕРВЕРА:8080/admin`.

Чтобы одобрять заявки, учётной записи Windows, под которой работает сервер, нужно право **записи** в `C:\Documentation`.

## Запуск, остановка, сброс
| Задача | Как |
|---|---|
| Запуск | `start_windows.bat` |
| Остановка | `Ctrl+C` в окне сервера или закрыть окно |
| Забыли пароль admin | `reset_admin_password.bat` на сервере |
| Сменить пароль | Админ-панель → Настройки |
| Резервная копия | Скопировать папку `data` (база, заявки, кэш предпросмотра) |

## Настройки (`start_windows.bat`)
| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DOC_ROOT` | `C:\Documentation` | Папка каталога |
| `DOC_META_DIR` | `C:\Documentation_ext` | Папка с `SIM_name.txt` / `SIM_number.txt` |
| `DOC_SHARE` | `\\%COMPUTERNAME%\Documentation` | UNC-путь к той же папке |
| `PORT` | `8080` | HTTP-порт |
| `UPLOAD_MAX_MB` | `500` | Лимит одной заявки |
| `UPLOAD_EXTS` | встроенный список | Разрешённые расширения через пробел |
| `APPROVE_ONLY_ON_SERVER` | `0` | `1` разрешает одобрять заявки только на ПК сервера |
| `SOFFICE`, `FFMPEG` | авто | Пути, если программы установлены не в стандартные папки |
| `DATA_DIR` | `.\data` | База, заявки и кэш |
| `TITLE_SCAN` | `1` | `0` выключает распознавание названий |

## Безопасность
- Приложение рассчитано на **доверенную локальную сеть**. Не публикуйте порт в интернет.
- Внутри сети трафик идёт по обычному HTTP, поэтому не используйте пароль admin в других системах.
- Сотрудник определяется по браузеру, IP и имени ПК, а не по учётной записи Windows. Имя вводит сам сотрудник.
- Защита от подбора: после 5 неудачных входов с одного IP вход блокируется на 15 минут.
- Файлы, которые браузер не умеет показать, никогда не отдаются для отображения. Скачивание всегда требует подтверждения.
